# Umar Syarif — Executive Portfolio & Profile

Official Executive Portfolio of **Umar Syarif** — Visionary Leadership, Strategic Innovation & Digital Transformation.

![Umar Portfolio](UMAR.png)

## 🚀 Overview

A modern, high-performance executive personal portfolio website built with Next.js 15, React 19, and TypeScript. Featuring cyber-modern aesthetics, interactive UI components, seamless animations, and instant advisory booking channels.

## ✨ Key Features

- **Hero Stage**: Dynamic introduction with interactive cyber glitch effects and bold typography.
- **Multi-Language Selector**: Built-in language selection for international audience engagement.
- **Infinite Marquee Loop**: High-impact brand and skill carousel.
- **Narrative Sections**:
  - About Me & Visionary Journey
  - Core Pillars of Expertise
  - Proven Track Record & Impact Milestones
  - Executive Endorsements & Testimonials
- **Advisory & Booking Integration**: Direct WhatsApp inquiry system for advisory bookings and collaborations.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with dark mode theme.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Typography**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
- **Styling**: Modern Vanilla CSS Design System with CSS variables and responsive breakpoints

## 🏁 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/r3ndyipb/umar-profile.git
   cd umar-profile
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build for Production

```bash
npm run build
npm run start
```
